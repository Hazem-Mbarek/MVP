# DATABASE
# ============================================================
Database: SQLite 3 (file-based)
Location: data/knowledge/company/database/loghub.db

Schema Files:
  - data/knowledge/company/database/create_sqlite.sql (operational tables)
  - data/knowledge/company/database/create_com.sql (commercial tables)

Seed Data:
  - data/knowledge/company/database/seed2.sql (all data: 44 employees, 18 clients, 88 jobs, 9 issues)

Python Database Access (optional):
  - sqlite3 (built-in with Python)
  - better-sqlite3 (npm package for Node.js)

# ============================================================
# EXTERNAL SERVICES
# ============================================================
OpenRouter API:
  - Provider: OpenRouter.ai
  - Purpose: AI model inference (Claude for chat, analysis)
  - Authentication: API Key (stored in environment variables)
  - Endpoints: https://openrouter.ai/api/v1/*
  - Models: Claude series (claude-opus, claude-sonnet, etc.)

Configuration:
  - Backend: OPENROUTER_API_KEY (backend/.env)
  - Frontend: NEXT_PUBLIC_BACKEND_URL (frontend/.env.local)

# ============================================================
# RUNNING THE APPLICATION
# ============================================================
Step 1: Install dependencies
  cd frontend && npm install
  cd ../backend && npm install

Step 2: Start the backend server
  cd backend
  npm run dev
  # Server runs on http://localhost:5000

Step 3: Start the frontend development server (in new terminal)
  cd frontend
  npm run dev
  # App runs on http://localhost:3001

Step 4: Access the application
  Open browser to http://localhost:3001

# ============================================================
# KEY FEATURES & PAGES
# ============================================================
Dashboard Pages:
  - Overview: Main landing page
  - Chatbot (/agents/attacker-agent): AI chat interface with OpenRouter
  - Processes (/processes): Automated process execution & monitoring
  - Knowledge Base (/knowledge-base): Company docs (CMR, Incoterms, procedures)
  - Settings (/settings): System configuration & admin controls

API Endpoints:
  - POST /api/chat: Send message to AI, get response

Database Features:
  - 44 employees across 8 departments
  - 2 operational warehouses (Dortmund, Leipzig)
  - 8 vehicles (FTL, LTL, moving trucks)
  - 18 clients across 5 countries
  - 88 jobs/shipments (Jan-Oct 2026)
  - 9 issues tracked (delays, damage, documentation)
  - CMR compliance documentation for cross-border shipments
